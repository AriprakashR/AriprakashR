### 🎫 Ticketing Tool
**A role-based service-management platform for tickets, machines, customers, and field operations.**

A centralized application for managing support tickets and service operations, with role-based access, operational dashboards, and reporting.

**Highlights**
- End-to-end ticket creation, assignment, status tracking, and history.
- Customer, employee, product, and machine records.
- Role-based access control for different employee responsibilities.
- Dashboards and reports for ticket trends, machine distribution, and productivity.
- Responsive, installable Progressive Web App (PWA).

**Technology:** React 19 · Vite 6 · Material UI 7 · React Router 7 · ApexCharts · Axios

🔗 **[View Ticketing Tool](https://github.com/Cloute-Technologies-Projects/Ticketing-Tool)**

### 📄 Quotation Tool
**A business application for quotations, invoicing, and inventory management.**

A centralized workspace for managing customer and supplier records, creating business documents, and tracking stock movement.

**Highlights**
- Create print-ready quotations, invoices, and delivery challans.
- Manage company details, customers, suppliers, and product catalogues.
- Track stock-in and stock-out transactions.
- View business activity through dashboards and reports.
- Generate PDF documents and use an installable PWA interface.
- Includes a mock-data mode for development and demonstrations.

**Technology:** React 18 · Vite · React Router 6 · Tailwind CSS · Material UI · Axios · React PDF

🔗 **[View Quotation Tool](https://github.com/Cloute-Technologies-Projects/Quotation-Tool)**

### 🧩 Qryio CRM — Web
**A role-aware CRM and support-ticketing platform for companies and their clients.**

A unified workspace for managing clients, projects, employees, and support tickets, with dashboards and access tailored to each user role.

**Highlights**
- Passwordless email-and-OTP authentication.
- Role-based experiences for company admins, client admins, company users, and client users.
- Client, employee, and project management.
- Ticket creation, attachments, status workflows, and project assignments.
- Analytics dashboards for ticket status, trends, projects, and clients.
- Session expiry and idle-activity handling.
- Mock API mode for development and demos.

**Technology:** React 19 · Vite · React Router 7 · Material UI 7 · ApexCharts · React Hook Form · Axios

🔗 **[View Qryio CRM Web](https://github.com/Cloute-Technologies-Projects/Qryio-CRM-Tool)**

### 📱 Qryio CRM — Mobile
**A mobile companion to the Qryio CRM and ticketing platform.**

A cross-platform mobile application that brings project and support workflows to internal teams and client organizations.

**Highlights**
- iOS, Android, and web support from a shared codebase.
- Role-based navigation for five user types.
- Email-and-OTP authentication with session persistence.
- Ticket and project workflows, including attachments and assignments.
- Analytics dashboards and idle-session protection.
- Offline mock-API mode for development and UI demonstrations.

**Technology:** Expo · React Native · Expo Router · React Native Paper · Axios · React Context · AsyncStorage

🔗 **[View Qryio CRM Mobile](https://github.com/Cloute-Technologies-Projects/Qryio-CRM-App)**
